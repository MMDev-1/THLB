Needs the repo owner

THLB lives on the personal account MMDev-1. Collaborators can push and merge, but only the account owner can let Vercel see the repo or change its branch rules — so both steps have to happen from that account.

Connect Vercel for PR previews

vercel.com → sign in with GitHub as MMDev-1 → Add New → Project → Import THLB → Deploy

If THLB isn't listed, choose Adjust GitHub App Permissions and allow it. From then on every PR, from any collaborator, gets a preview URL comment.

Protect main

Settings → Branches → Add rule → main → Require a pull request before merging

GitHub currently reports protected: false, and one commit already went straight to main. Requiring approvals too means someone other than the author must approve each PR.
