### What's in it

- **Homepage assembly:** `data/home.json` is now an ordered list of sections, each with a `type`. `app/page.tsx` renders them through **`SectionRenderer`**. The hero and category tiles load first. The six sections below the fold are split into separate chunks with `next/dynamic`.
- **Shared `Carousel`** (`components/ui/Carousel.tsx`): taken out of the T3-S3 product track, so products and reviews share one scroll-snap, arrow and keyboard implementation.

### Design decisions

| Decision                                                               | Why                                                                                                                                                                 |
| ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `SectionRenderer` is a `switch` on `section.type` with a `never` check | If a new section type is added to `home.json` without a component, the type check fails. Otherwise the section would silently render nothing.                       |
| Sections validated as a Zod discriminated union                        | `npm run validate:data` names the exact section and field that is wrong, not just "invalid union".                                                                  |
| One `Carousel` for products and reviews                                | The arrows, edge detection and ←/→ keys are written once. A bug fixed there is fixed in both places.                                                                |
| Reviews: rating ≥ 4, verified first, then newest                       | The homepage shows the strongest real reviews. Both the limit (6–8) and the minimum rating are set in `home.json`.                                                  |
| Email checked with a small pattern, not Zod, in the browser            | Using Zod in a client component added about 84 KB of JavaScript to the homepage (73 KB of it unused). The email provider does the final check once it is connected. |
| Size picker loaded on demand                                           | Radix Popover is only needed after a tap. It loads when the button is hovered or focused, so it is ready by the click.                                              |
| Hero uses `<picture>` (art direction)                                  | Phones download only the mobile image, where before they downloaded both.                                                                                           |
| Darker ember (`ember-700`) for small orange text and buttons           | White on `--primary` (#c75b2a) is 4.23:1. WCAG AA needs 4.5:1 for text this size.                                                                                   |
