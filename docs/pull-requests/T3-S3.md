## T3-S3: ProductCard + ProductCarousel

> Merged in [#16](https://github.com/MMDev-1/THLB/pull/16) on 14 Sep 2026. CI passed on the PR and on `main`.

### What's in it

- **ProductCard** (`components/product/ProductCard.tsx`): a card shared by the homepage, collection pages, upsells and search. It has a 4:5 image with a second image on hover, a badge, a wishlist heart, price with % off, colour dots, stars and review count, and quick add.
- **ProductCarousel** (`components/sections/ProductCarousel*.tsx`): the "Best Sellers" section on the homepage. It reads product handles from `home.json` and loads them through `getProducts()`.

### Design decisions

| Decision                                                  | Why                                                                                                                                                                        |
| --------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Card view model (`toProductCardData`) built on the server | A product has up to 48 variants and about 190 image entries. The card needs only a few hundred bytes, so pages don't ship whole products to the browser.                   |
| Stretched title link for "whole card is a link"           | Buttons nested inside a link are invalid HTML. The link's clickable area covers the card, the controls sit above it, and they stop propagation.                            |
| Native scroll-snap instead of a slider library            | This is what the spec asks for. Swiping on touch comes free.                                                                                                               |
| Radix Popover for the size picker                         | It renders outside the card, so the carousel can't clip it. It also handles focus, Escape and outside clicks. It's the same family as the 9 Radix packages already in use. |
| "One variant → add directly" applies to the colour shown  | Otherwise one-size items like the blanket would open a picker with a single choice.                                                                                        |
| Minimal `store/cart.ts`                                   | Quick add needs a real place to put items, and the header badge now shows the live count. The full cart comes with the cart task.                                          |
